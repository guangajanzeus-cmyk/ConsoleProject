# ConsoleProject

A collection of Java console programs built while learning Object-Oriented Programming (OOP) fundamentals — classes, methods, and constructors — through a hands-on Java course.

Each program is a standalone application that runs independently, focused on practicing a different OOP concept or problem-solving pattern.

## Programs Included

| Program | Description |
|---|---|
| **Banking Program** | An ATM-style simulator with a menu system — users can choose actions like deposit, withdraw, or check balance. |
| **Calculator Program** | A console-based calculator that takes user input and performs basic arithmetic operations. |
| **Shopping Cart / Inventory System** | Manages products and inventory — includes adding items to a cart and tracking stock through a product list. |
| **Number Guessing Game** | A simple interactive game where the user guesses a number based on program feedback. |
| **Alarm Clock** | A console program simulating a basic alarm clock. |
| **Color Game** | A single-class OOP program (originally `Main.java`) built around a color-guessing/matching mechanic. |

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes & Objects
- Methods
- Constructors
- User input handling (console I/O)
- Basic program flow and menu-driven logic

## How to Run

Each program is self-contained. To run a specific program:

1. Clone or download this repository
2. Open the project in your Java IDE (e.g. IntelliJ IDEA)
3. Open the `.java` file for the program you want to run (e.g. `BankingProgram.java`)
4. Run that file directly — it has its own `main` method
